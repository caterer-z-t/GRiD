IBS/IBD Neighbor Computation Example¶

This example demonstrates Stage 2 of the GRiD workflow: using computeIBSpbwt to generate the IBS neighbors file required by GRiD for haploid copy number estimation (Step 5).

The script automatically sources locus coordinates (chromosome and focal midpoint) derived during Stage 1 from data/pipeline_vars.sh.

02-run-ibs.sh — Stage 2: Compute IBS neighbors via PBWT¶
  1#!/bin/bash
  2#SBATCH --job-name=grid_ibs
  3#SBATCH --output=slurm/%x.out
  4#SBATCH --error=slurm/%x.err
  5#SBATCH --time=2-00:00:00
  6#SBATCH --cpus-per-task=4
  7#SBATCH --mem=100G
  8
  9# Stage 2 of 3 — compute IBS neighbors (needed for haploid CN estimation).
 10# Submit after 01_prep_data.sh completes; sources data/pipeline_vars.sh for
 11# CHR/FOCAL_BP rather than re-deriving them, so this can't disagree with
 12# stage 1's locus coordinates.
 13#
 14# Usage: sbatch 02_run_ibs.sh   (from the same working directory as stage 1)
 15
 16set -euo pipefail
 17
 18module load samtools
 19
 20NUM_NEIGHBORS=200
 21while [[ $# -gt 0 ]]; do
 22    case $1 in
 23        --num-neighbors) NUM_NEIGHBORS="$2"; shift 2 ;;
 24        -h|--help)
 25            echo "Usage: $0 [--num-neighbors N]"
 26            exit 0 ;;
 27        *)
 28            echo "Unknown argument: $1"
 29            exit 1 ;;
 30    esac
 31done
 32
 33WORK_DIR="${WORK_DIR:-$(pwd)}"
 34LOG_DIR="$WORK_DIR/logs"
 35DATA_DIR="$WORK_DIR/data"
 36OUTPUT_DIR="$WORK_DIR/output"
 37mkdir -p "$DATA_DIR" "$LOG_DIR" "$OUTPUT_DIR" "$WORK_DIR/slurm"
 38
 39THREADS="${SLURM_CPUS_PER_TASK:-$(nproc)}"
 40
 41timestamp() { date '+%Y-%m-%d %H:%M:%S'; }
 42log() { echo "[$(timestamp)] $*" | tee -a "$LOG_DIR/IBS.log"; }
 43
 44download_with_retry() {
 45    local url="$1" out="$2" attempt
 46    for attempt in 1 2 3 4 5; do
 47        if wget -q --tries=1 --timeout=60 -O "$out" "$url"; then
 48            return 0
 49        fi
 50        rm -f "$out"
 51        sleep $(( attempt * 3 + RANDOM % 3 ))
 52    done
 53    echo "ERROR: failed to download $url after 5 attempts" >&2
 54    return 1
 55}
 56
 57# --- Load locus coordinates written by 01_prep_data.sh ---
 58VARS_FILE="$DATA_DIR/pipeline_vars.sh"
 59if [[ ! -f "$VARS_FILE" ]]; then
 60    echo "ERROR: $VARS_FILE not found — run 01_prep_data.sh first."
 61    exit 1
 62fi
 63source "$VARS_FILE"
 64
 65if ! command -v "$WORK_DIR/qctool/qctool" &> /dev/null; then
 66    log "Installing qctool..."
 67    download_with_retry \
 68        "https://www.well.ox.ac.uk/~gav/resources/qctool_v2.2.0-CentOS_Linux7.8.2003-x86_64.tgz" \
 69        "$WORK_DIR/qctool.tgz"
 70    tar -xzf "$WORK_DIR/qctool.tgz" -C "$WORK_DIR"
 71    mv "$WORK_DIR/qctool_v2.2.0-CentOS Linux7.8.2003-x86_64" "$WORK_DIR/qctool"
 72    rm -f "$WORK_DIR/qctool.tgz"
 73fi
 74
 75MISSING=()
 76for cmd in "$WORK_DIR/qctool/qctool" wget samtools; do
 77    command -v "$cmd" &>/dev/null || MISSING+=("$cmd")
 78done
 79if [[ ${#MISSING[@]} -gt 0 ]]; then
 80    log "ERROR: missing required tools: ${MISSING[*]}"
 81    exit 1
 82fi
 83
 84COMPUTE_IBS="$WORK_DIR/computeIBSpbwt"
 85if [[ ! -f "$COMPUTE_IBS" ]]; then
 86    log "Downloading computeIBSpbwt binary..."
 87    download_with_retry \
 88        "https://raw.githubusercontent.com/mhujoel/STRs/main/cpp_files/computeIBSpbwt" \
 89        "$COMPUTE_IBS"
 90    chmod +x "$COMPUTE_IBS"
 91fi
 92
 93PHASED_VCF_URL="https://ftp.1000genomes.ebi.ac.uk/vol1/ftp/data_collections/1000G_2504_high_coverage/working/20220422_3202_phased_SNV_INDEL_SV/1kGP_high_coverage_Illumina.chr${CHR}.filtered.SNV_INDEL_SV_phased_panel.vcf.gz"
 94GENETIC_MAP_URL="https://alkesgroup.broadinstitute.org/Eagle/downloads/tables/genetic_map_hg38_withX.txt.gz"
 95
 96LPA_VCF="$DATA_DIR/1kGP_chr${CHR}_LPA_phased.vcf.gz"
 97BGEN_FILE="$DATA_DIR/1kGP_chr${CHR}_LPA_phased.bgen"
 98SAMPLE_FILE="$DATA_DIR/1kGP_chr${CHR}_LPA_phased.sample"
 99GENETIC_MAP="$DATA_DIR/genetic_map_hg38_chr${CHR}.txt"
100OUTPUT_FILE="$DATA_DIR/ibs_neighbors_chr${CHR}.tsv.gz"
101
102# --- Stream LPA region from the 1000G phased VCF ---
103if [[ ! -f "$LPA_VCF" ]]; then
104    log "Streaming LPA region from 1000G phased VCF..."
105    tabix -h "$PHASED_VCF_URL" "$REGION" | bgzip > "$LPA_VCF"
106    tabix -p vcf "$LPA_VCF"
107    find "$WORK_DIR" -maxdepth 1 -name "*.tbi" ! -path "${LPA_VCF}.tbi" -delete
108    log "LPA phased VCF ready: $LPA_VCF"
109else
110    log "LPA phased VCF already present — skipping."
111fi
112
113# --- Convert phased VCF -> BGEN v1.2 ---
114if [[ ! -f "$BGEN_FILE" ]]; then
115    log "Converting phased VCF to BGEN v1.2..."
116    "$WORK_DIR/qctool/qctool" \
117        -g "$LPA_VCF" \
118        -og "$BGEN_FILE" \
119        -os "$SAMPLE_FILE" \
120        -ofiletype bgen_v1.2 \
121        -bgen-bits 16 \
122        -bgen-permitted-input-rounding-error 0 \
123        >> "$LOG_DIR/qctool.log" 2>&1
124    log "BGEN file ready: $BGEN_FILE"
125else
126    log "BGEN file already present — skipping."
127fi
128
129# --- Download + decompress + filter Eagle genetic map ---
130# The map's chrom column is bare (e.g. "6"), not "chr6" — filtering on
131# "chr${CHR}" here would silently match nothing and produce a header-only
132# file, so this must stay as the bare chromosome number.
133if [[ ! -f "$GENETIC_MAP" ]]; then
134    log "Downloading Eagle hg38 genetic map..."
135    wget -q -O - "$GENETIC_MAP_URL" \
136        | gunzip \
137        | awk -v c="${CHR}" 'NR==1 || $1==c' \
138        > "$GENETIC_MAP"
139    log "Genetic map ready: $GENETIC_MAP"
140else
141    log "Genetic map already present — skipping."
142fi
143
144# --- Run computeIBSpbwt ---
145log "Computing IBS neighbors..."
146log "  CHR=$CHR  FOCAL_BP=$FOCAL_BP  NEIGHBORS=$NUM_NEIGHBORS  THREADS=$THREADS"
147
148"$COMPUTE_IBS" \
149    "$CHR"          \
150    "$FOCAL_BP"     \
151    "$BGEN_FILE"    \
152    "$SAMPLE_FILE"  \
153    "$GENETIC_MAP"  \
154    "$NUM_NEIGHBORS"\
155    "$THREADS"      \
156    "$OUTPUT_FILE"
157
158log "IBS neighbors written to: $OUTPUT_FILE"
159log "Next: submit 03_generate_config_and_run.sh"

Key Parameters & Environment Variables¶

The coordinates and variables used by 02-run-ibs.sh are sourced dynamically from Stage 1 (data/pipeline_vars.sh) or can be passed via command line options:

Parameter / Variable

Description

--num-neighbors

Number of IBS neighbors per haplotype (default: 200).

CHR

Target chromosome (e.g., 6, exported by Stage 1).

FOCAL_BP

Base pair position at center of VNTR (e.g., LPA KIV-2 midpoint in hg38, exported by Stage 1).

COMPUTE_IBS

Path to the auto-downloaded or local computeIBSpbwt binary.

PHASED_VCF_URL

1000 Genomes high-coverage phased VCF URL streamed for the target region via tabix.

GENETIC_MAP

Eagle hg38 genetic map auto-downloaded and filtered for chromosome CHR.

OUTPUT_FILE

Compressed output path (data/ibs_neighbors_chr${CHR}.tsv.gz).

Usage¶

Submit to SLURM after 01-prep-data.sh completes:

sbatch examples/02-run-ibs.sh

Override the default number of neighbors:

sbatch examples/02-run-ibs.sh --num-neighbors 100

Passing Output to GRiD¶

Stage 3 (03-run-grid.sh) automatically detects data/ibs_neighbors_chr${CHR}.tsv.gz upon completion and embeds the path directly into config.yaml:

compute_haploid_genotypes:
  run: True
  output_file_prefix: "haploid_genotypes"
  ibs_output: "data/ibs_neighbors_chr6.tsv.gz"
  min_neighbors: 1
  max_neighbors: 10
  n_iters: 100
  method: "ibs"
